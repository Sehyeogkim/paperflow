# Initial vertical hypothesis: CFD simulation handover and failure memory

2026-08-10 인터뷰 기록은 특정 pain point를 검증하지 못했고, 범용 knowledge management 대신 특정 vertical의 반복적인 knowledge-transfer 문제를 찾으라는 조언만 확인했다.

현재 가장 근거가 있는 초기 vertical 가설은 **CFD/계산공학 연구실의 시뮬레이션 재현·디버깅·인수인계**다. 창업자가 Claude Code에 성공/실패 기록, 사고과정, 연구실 로그를 제공했을 때 직접 성능 향상을 경험했으며, 입력 파일·solver log·코드·결과 등 디지털 흔적도 풍부하다.

초기 JTBD는 “이전 연구자의 simulation case를 넘겨받은 대학원생이 왜 이 설정을 선택했고 무엇이 실패했는지 파악해 다음 run을 안전하게 결정한다”이다. AET는 제품 시연용 사례이며, 독립적인 고객 pain이 확인되기 전에는 시장 vertical로 확정하지 않는다.
