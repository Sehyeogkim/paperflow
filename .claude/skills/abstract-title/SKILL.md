# /abstract-title — Step 6: Abstract + Title (last)

Write these LAST. The abstract is a condensation of a finished paper; the title should convey the finding, not the topic.

## 1. Find the paper directory & read context
- Resolve the paper dir. Read `1_coremessage.md`, `3_outline.md`, and all drafts in `4_contents/`.
- Read `0_journal_info.md` for the working title and the target journal's abstract rules.

## 2. ▶ Ask first (in Korean)
- 모든 섹션 초안이 확정됐나? (안 됐으면 abstract는 이르다 — 먼저 마무리 권유)
- 타깃 저널의 abstract **형식·길이 제한**은? (structured vs unstructured, 단어수)
- 제목은 **발견(finding)**을 담을까, 어디까지 구체화할까?

## 3. Rules
- **Abstract = 핵심메시지 + 핵심 결과의 압축.** 새 내용 추가 금지, 본문과 수치 일치.
  구조: 배경 1–2문장 → gap → 한 일 → 핵심 결과(수치) → 함의.
- **Title**: topic형("~에 대한 연구") 금지. 발견을 담되 저널 관례에 맞게. 확정 제목으로 `0_journal_info.md`의 Working title 갱신.
- 한국어 초안 → 영어 번역, `writing_style/` 용어/길이 준수.

## 4. Save
Write `<paper>/4_contents/abstract.md`; update the title line in `<paper>/0_journal_info.md`.

## 5. Gate → 마무리
초안 전체가 모이면 제출 전 점검: `polish`(LaTeX·문법·포맷) + `reference-double-checker`(인용 검증) + `reviewer`/`advisor` 최종 리뷰.
Respond in Korean; keep title / citations / technical terms in original language.
