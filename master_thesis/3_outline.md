# Outline  (workflow step 3)

이 파일은 두 phase로 채운다. **Phase A를 먼저 통과시킨 뒤** Phase B로 넘어간다.

## Phase A — Skeleton (논리 점검)
문단(paragraph)마다 **주장 한 문장**씩. 이 문장들만 위→아래로 이어 읽었을 때
논리가 점프 없이 흐르는지 확인한다. (소제목당 한 줄로 굵게 시작 → 필요한 데서 문단 단위로 쪼갠다.)

<!-- 예시
Intro
- 문장1: AAA 파열 위험은 벽응력으로 좌우된다.
- 문장2: 그러나 FSI 해석은 계산비용이 커서 임상 적용이 어렵다.
- 문장3: 따라서 비용효율적 surrogate 기반 framework가 필요하다.
Method
- ...
-->

## Phase B — Outline (구조 확장)
Phase A가 논리적으로 흐르면, 소제목(2.1, 2.2 ...) 구조로 확장한다. Intro → Conclusion.
