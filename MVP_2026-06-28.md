# PaperFlow MVP — 2026-06-28

## Demo promise

사용자가 다음을 제공한다.

1. journal/user information
2. core message
3. data/result files + file descriptions
4. research plan/related documents/references
5. optional outline

PaperFlow는 관련 문헌을 조사하고, 연구 상태와 잠정 logic graph를 만든 뒤, graph를 완성하기 위한 질문을 한다. 답변 후 final logic graph를 확정하고 전체 논문 초안을 생성하여 DOCX와 read-only preview로 제공한다.

## Demo acceptance test

한 개의 실제 연구 프로젝트에서:

- outline 파일을 제거한다.
- research plan과 data만 업로드한다.
- PaperFlow가 research state를 생성한다.
- 최소 한 차례 질문/답변을 수행한다.
- final logic graph를 만든다.
- 전체 초안을 생성한다.
- DOCX가 다운로드된다.
- 같은 내용이 오른쪽 preview에 표시된다.

이 흐름이 한 번 끊김 없이 동작하면 MVP 성공으로 본다.
